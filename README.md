## ✿ что это

**DOOM MOE** — маленький шутер от первого лица, который выглядит как
плюшевая игрушка, а пахнет порохом. Ты бежишь по процедурно
сгенерированному лабиринту из розовых комнат, стреляешь в пиксельных
котиков-демонов, собираешь капкейки, находишь секреты, копишь ключи и
открываешь запертые двери, чтобы добраться до портала.

Всё, что ты видишь и слышишь — **нарисовано и синтезировано кодом**:
ни одной внешней картинки, ни одного `.mp3`. Только `<canvas>`,
Web Audio API и three.js.

## ✿ концепция

> *«Что если Doom, но милый. И жуткий. Одновременно.»*

- 🌸 **эстетика** — пастельные тона, розовый, кружево, бантики,
  сердечки — поверх мрачных стен и кровавых брызг.
- 🔪 **настроение** — сладкое с горчинкой: сообщения о секретах звучат
  как колыбельные из плохого сна.
- 👾 **мир** — процедурный. Каждый запуск — новый уровень, новые
  комнаты, новые секреты. Никогда не повторяется.

## ✿ управление

### ⌨️ Клавиатура и мышь

| Клавиша | Действие |
|---|---|
| `W` `A` `S` `D` | движение |
| `Мышь` | обзор |
| `ЛКМ` | стрелять / бросить гранату |
| `Space` | прыжок |
| `Q` или `1` | сменить оружие |
| `E` | взаимодействие (прочитать секрет / открыть дверь ключом) |
| `ESC` | пауза, `ESC` ещё раз — вернуться в игру |

> 💡 Если мышь не захвачена — кликни по экрану.

### 📱 Тачскрин

- **Левый нижний угол** — виртуальный стик для движения.
- **Правый нижний угол** — кнопки `FIRE`, `JUMP`, `SWAP`, `USE`.
- Обзор — свайп по экрану.

## ✿ как играть

1. Нажми **START GAME**.
2. Иди к розовому порталу в дальнем конце уровня.
3. По пути стреляй в котиков и кроликов.
4. Ищи **секреты** — они дают очки и **ключи**.
5. Ключами открывай **запертые двери** (на них нарисован замочек).
6. Убей **80% демонов** и дойди до портала — уровень пройден.

На HUD: слева сверху — очки, счётчик демонов и время.
Снизу слева — сердечко HP и пиксельный ключик с количеством.
Снизу справа — оружие и патроны (у винтовки — бесконечные).

## ✿ технологии

- **three.js** — 3D-рендер, спрайты, инстансинг, шейдеры
- **Web Audio API** — все звуки и музыка синтезируются в реальном времени
- **Canvas 2D** — генерация всех текстур (стены, враги, предметы, HUD)
- **CSS** — экраны, меню, анимации, pixel-art надписи
- **LocalStorage** — сохранение настроек

---

## ✿ настройки

- **Mouse sens** — чувствительность мыши
- **Master / Music / SFX vol** — громкость
- **Music track** — выбор трека или `SHUFFLE (ALL)` (по умолчанию)
- **CRT filter** — включить/выключить ретро-эффекты

## ✿ фон меню

Положи свои картинки в папку `img/`:

```
img/menu-bg-1.png
img/menu-bg-2.png
img/menu-bg-3.png
```

Они автоматически подхватятся: фон меняется **по клику** и **раз в 10 секунд**.
Если файлов нет — будет градиент. Ничего не сломается.

## ✿ запуск

Просто открой `index.html` в браузере — но лучше через локальный сервер,
потому что мы используем ES-модули.

```bash
# python
python -m http.server 8000

# или node
npx serve
```

Затем открой `http://localhost:8000`.
